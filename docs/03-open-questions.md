## 阻擋型

### Q1. 獎勵制度是否存在

原文承諾四項產品：QXP 幣、「SSS 糾纏先鋒」稱號、實體 NFC 徽章、QRACON 冒險者系統。

需要確認：已規劃、規劃中、還是沒有？

- 已規劃 → 補正式名稱、取得條件、兌換方式，寫進 `01-copy-deck.md` §6。
- 沒有 → 永久刪除。

**影響**：結果頁的第三個 CTA、整體文案可信度。

### Q2. 部署方式（子路徑已定，合併方式未定）

`/tarot` 子路徑已由審核核准，但**建置怎麼合併**還沒決定（`02-plan.md` §11）：

| 方案 | 做法 | 代價 |
| --- | --- | --- |
| A（建議） | 塔羅站成為主站 repo 的 `apps/tarot`，單一建置 | 要搬一次 repo |
| B | 兩個 repo，主站 CI 拉塔羅站產物 | cross-repo token、版本對齊 |
| C | 獨立子網域 `tarot.entangletech.tw` | SEO 權重不共用 |

**不接受**直接部署到根目錄（會覆蓋主站）。

**影響**：P1 的 `base` 設定與部署腳本。晚改要動全站連結。

## 影響設計

### Q4. 五張牌改名

原文的牌名與它標的量子概念對不上，v2 建議改名（理由見 `00-source-audit.md` B1–B3）：

| 原牌名 | v2 | 理由 |
| --- | --- | --- |
| 量子糾纏純愛戰士 | 糾纏態純愛戰士 | 與其他牌命名格式一致（概念＋角色） |
| 絕對零度冷酷貓 | 觀測者冷酷貓 | 絕對零度是熱力學，不是測量 |
| 量子躍遷幸運星 | 躍遷幸運星 | 同上格式 |
| 高能塌縮災難大師 | 淬火災難大師 | 「高能塌縮」不是標準術語 |
| 全光子熱情太陽貓 | 相干光太陽貓 | 「全光子」不是形容詞 |

愚者、死神維持原名。需要設計組確認：牌面插畫上的文字要跟著改。

### Q5. 「運勢」這個詞

牌義頁目前用「最近的運勢」。有人會讀成命理預測。

替代方案：「最近的狀態」。更準，但少了一點占卜的趣味。

**影響**：七張牌的欄位標題、分享卡文案。

### Q6. 物理校稿

七個名詞的解釋是照一般科普寫的。需要一位物理背景的成員簽過，特別是：

- 「至於為什麼會坍縮，量子力學到現在還沒有共識」這句的措辭。
- 「糾纏不能用來超光速傳訊息」這句要留。
- 淬火要不要出現「能量規則」以外的詞（Hamiltonian 對一般讀者太硬，v2 已改成「能量規則」）。

**影響**：文案定稿、關於頁署名。

### Q7. 牌背的「O」紋樣

直接從字標 PNG 裁切，或請設計組出一個向量版？

裁切解析度夠（1696px 寬），但放大會模糊。牌背在手機上是 88–132px 寬，2x 需要 264px，裁切足夠。
