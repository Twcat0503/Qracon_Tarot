## 一頁摘要

**是什麼**：手機優先的單頁互動。七張牌背朝上的塔羅牌扇形展開，點一張，其餘六張碎散，被選的那張翻開，接著展開成一張票券狀的「量子狀態觀測報告」。30–60 秒完成，最後導向議程與報名。

**技術**：Astro 靜態輸出、零框架、原生 CSS。與主站 `qracon_web_2026` 同源，字標、躍貓、字型、tokens、票券元件直接沿用。沒有 WebGL、沒有動畫函式庫。

**視覺建議**：暗房（墨黑場 + 紙白牌面 + 銀墨高光，零色相）。初稿曾建議全像箔，經審核查證主視覺飽和度為 0 後刪除。理由與替代方案見 `02-plan.md` §3。

**這次做了什麼**：

- 把原文 17,452 bytes 梳理成 7,000 bytes 的可上線文案，移除 6 種 7 處 emoji、16 條誇示／討好語、3 組重複段落。
- 修正 9 處物理名詞與牌名不符（例如「絕對零度」配「波函數塌縮」），另修正 3 處實質物理錯誤（疊加、淬火、退相干）。
- 把 5 項未證實的產品承諾（QXP 幣、SSS 稱號、NFC 徽章、冒險者系統、分享到 IG）標成待確認，不寫成既成事實。
- 補上原文缺的規格：屬性四軸、重抽規則、鍵盤與 reduced-motion、分享機制、效能預算、插畫資產規格。
- 送 Gemini 4 核定兩輪：第一輪有條件核定（9 項 P0），全部處理後第二輪**核定**。7 項物理修正全採納，新增 3 條風險（部署覆蓋、WebView 分享失效、無預取轉場）。
